# لمّة تلاتة — ملفات GitHub Pages

ارفع ملفات الموقع إلى جذر المستودع:
- `index.html`
- `anime-friends.png`
- `manifest.webmanifest`
- `sw.js`
- `icon.svg`

شغّل كامل `supabase-setup.sql` مرة واحدة في Supabase SQL Editor. الملف يجهز جداول الشات والذكريات والخروجات، تخزين الصور الخاص، وكلمات مرور التطبيق الإضافية المشفرة. تشغيله مرة أخرى آمن ولا يحذف جدول النسخة القديمة.

كل صاحب يدخل بحساب Supabase الأساسي لربط المستخدم. بعد ذلك يضبط كلمة مرور تطبيق منفصلة، وتُطلب عند فتح التطبيق كل مرة. كلمة مرور التطبيق لا تُحفظ كنص مكشوف؛ تُخزن كبصمة مشفرة على قاعدة البيانات. يمكن تغييرها من داخل التطبيق، أو إعادة ضبطها بعد إثبات حساب Supabase الأساسي.

## التثبيت

بعد النشر عبر GitHub Pages HTTPS:
- Android: زر **تثبيت التطبيق** أو قائمة Chrome → **إضافة إلى الشاشة الرئيسية**.
- Windows: افتح الموقع في Edge أو Chrome واختر **تثبيت التطبيق** من الزر أو قائمة المتصفح.

التطبيق يحتاج الإنترنت للشات والمزامنة ورفع الصور.
