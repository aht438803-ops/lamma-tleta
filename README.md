# لمّة تلاتة — ملفات GitHub Pages

ارفع كل الملفات التالية إلى جذر المستودع:
- `index.html`
- `anime-friends.png`
- `manifest.webmanifest`
- `sw.js`
- `icon.svg`

قبل استخدام الحفظ والمزامنة، شغّل `supabase-setup.sql` مرة واحدة في Supabase SQL Editor. الإعداد يضيف جداول الرسائل والذكريات والخروجات وإعداد الغلاف ومخزن صور خاص، ولا يحذف جدول النسخة السابقة.

## التثبيت على الأجهزة

بعد النشر على GitHub Pages وفتح الموقع عبر HTTPS:
- Android: اضغط **تثبيت التطبيق** داخل الموقع أو من قائمة Chrome اختر **إضافة إلى الشاشة الرئيسية**.
- Windows: افتح الموقع في Edge أو Chrome واضغط **تثبيت التطبيق**، أو اختر التثبيت من قائمة المتصفح.

الواجهة والملفات الثابتة يمكن فتحها بعد تثبيت التطبيق؛ المزامنة والحفظ ورفع الصور تحتاج اتصال إنترنت.
